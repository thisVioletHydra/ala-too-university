# Приложение

Папка собирает рабочую область расписания и связывает интерфейс с данными и действиями пользователя.

Основные механизмы:

- Загрузка каталога, восстановление сохранённого расписания и переключение набора данных.
- Общее хранилище занятий с проверкой конфликтов, отменой и повтором изменений.
- Состояние доски: выбранная карточка, цель переноса, редактор и обратная связь после действия.
- Подключение перетаскивания мышью и команд рабочей области к общим правилам размещения.
- Компоновка списка секций, сетки, фильтров и редактора.

Предметные правила расписания, навигация и компоненты интерфейса остаются в соответствующих папках. Здесь находится их соединение в приложение.
