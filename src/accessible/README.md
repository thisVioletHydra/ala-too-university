# Доступное управление интерфейсом

Папка отвечает за удобство работы без мыши, управление фокусом и общие механизмы поддержки скринридеров.

## Ключевые механизмы

- Семантические клавиатурные команды, сочетания для разных платформ и подсказки.
- Навигация по сетке, спискам и боковой панели. Циклический обход групп и пропуск недоступных элементов.
- Начальный фокус окна, удержание Tab внутри диалога и возврат к исходному элементу.
- Прокрутка к текущей цели с учётом предпочтения уменьшенной анимации.
- Определение способа ввода и контекста события: поле ввода, область интерфейса или открытое окно.
- Короткие объявления результата действий через область статуса, без переноса фокуса.

## Границы ответственности

Общие механизмы принимают элементы, команды и обработчики. Они не решают, куда назначить занятие, и не меняют расписание.

Сценарий приложения выбирает действие, текст объявления и цель возврата фокуса. Компоненты сохраняют семантическую HTML-разметку и связанные с ней ARIA-атрибуты рядом с отображаемыми элементами.

Нативные возможности браузера используются прежде дополнительных механизмов. Общая функция нужна для повторяющегося поведения, а не для каждого атрибута или обработчика.
