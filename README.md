# Расписание

Один экран: список секций и сетка Пн–Пт. Занятия перетаскиваются, конфликты считаются до Drop.

```bash
pnpm install && pnpm dev
```

Тесты: `pnpm test`.

Ошибка загрузки: откройте `/?fail=1` и нажмите «Повторить».

## Архитектура

- `schedule/` — чистый TS, правила предметной области
- `app/schedule.store.ts` — единственное место изменения `lessons` и история снимков
- `features/` — хуки, шлют намерения в стор
- `ui/` — компоненты, рисуют готовые результаты
- `data/` — мок, загрузка, localStorage
- `accessible/` — клавиатура: пробел берёт карточку, Tab переключает список и сетку, стрелки двигают фокус, пробел кладёт

## Карточка в руке

Экземпляр всегда один: у взятой карточки в клетке остаётся только коробка (`opacity: 0`), поэтому сетка не прыгает, а летит и опускается ровно эта же карточка. Летящая стартует из прямоугольника исходной и уезжает к цели за 150 мс, так что подъём читается как движение, а не как подмена. У списка секций наоборот: секция никуда не уходит, поэтому её карточка остаётся на месте приглушённой.

Курсор клавиатуры при взятии карточки переезжает в её собственную клетку — иначе пунктир цели оставался там, где он был до этого.

## Визуальный слой

- `app/tokens.css` — единственное место с цветами, тенями и радиусами; в модулях только `var(--…)`
- оттенок курса задаётся одним `--h` на `[data-course]`, из него выводятся чип, рейка и прогресс: насыщенность в мелких деталях, бледность в больших заливках
- акцент оставлен тому, что требует решения: состояние прогресса, предупреждение об аудитории, подсветка допустимых и недопустимых слотов, попадание в фильтр
- состояния Drag & Drop (`data-tone`, `data-over`, `data-aim`, `data-held`, `data-dim`) рисуются только в CSS
- возврат в нераспределённые — короткое затухание на месте; карточка не летит через весь экран в список

## Что не делали специально

Сервер, авторизация, база и вторая страница. В слот можно поставить сверх нормы. Две карточки местами не меняются. `preferredRoomType` — мягкий. `allowedTeacherIds` — ограничение выбора, не шестое правило. В одной клетке может стоять несколько занятий, если преподаватель, аудитория и секция не пересекаются. Выходной из интерфейса не добавляется.

## Отложено из бонусов

Виртуализация списка: `schedule/virtual-window.ts`, заглушка. Когда включат, только у списка, карточка фиксированной высоты, при меньше чем 50 секциях выключена. Screen reader не входит.
