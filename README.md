# Расписание

Прототип недельного расписания университета: секции, занятия и проверка конфликтов на одном экране. [Демо](https://thisviolethydra.github.io/ala-too-university/) · [Репозиторий](https://github.com/thisVioletHydra/ala-too-university).

React 19 с Compiler, TypeScript, Vite, Zustand, dnd-kit и CSS Modules. Проверки — Oxlint и Vitest.

## Запуск

Нужен pnpm версии, закреплённой в `package.json`.

```bash
pnpm install
pnpm dev
```

- `pnpm test` — тесты.
- `pnpm lint` — проверка кода; `pnpm lint:fix` — исправления.
- `pnpm build` — проверка TypeScript и сборка; `pnpm preview` — её просмотр.

Ошибка загрузки демонстрируется через `/?fail=1`. В настройках доступен набор из 500 секций.

## Архитектура

Папки внутри `src/`:

- `app/` — загрузка, хранилище с историей, состояние доски и компоновка.
- `schedule/` — чистые правила расписания и проверки конфликтов.
- `interaction/` — правила переноса и групп карточек без React и DOM.
- `features/` — пользовательские сценарии, поиск, группировка и сохранение.
- `accessible/` — карта клавиш, навигация, фокус и объявления.
- `ui/` — компоненты и оформление.
- `data/` — mock-данные, их разбор и localStorage.

Подсветка и изменения расписания используют общие предметные проверки. История хранит снимки занятий. Преподаватель назначается всей секции; предпочтительный тип аудитории — мягкое условие. Занятия сверх недельной нормы разрешены и отмечаются отдельно.

## Управление

Карточку можно перетащить или взять и поставить кликами. Карандаш на занятии появляется при наведении.

Стрелки — навигация, Пробел — взять/поставить, Enter — редактор, Shift — повторное размещение, Tab — смена области, Delete/Backspace — удалить, Escape — отменить.

Command на macOS / Ctrl на Windows: Z — отмена, Shift+Z — повтор, K — поиск. На Windows также Ctrl+Y.
