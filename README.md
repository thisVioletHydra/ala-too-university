# Расписание

Один экран: список секций и сетка Пн–Пт. Занятия перетаскиваются, конфликты считаются до Drop.

```bash
pnpm install && pnpm dev
```

Тесты: `pnpm test`.

Ошибка загрузки: откройте `/?fail=1` и нажмите «Повторить».

## Архитектура

- `schedule/` — чистый TS, правила предметной области
- `app/schedule.store.ts` — единственное место изменения `lessons` и история снимков
- `features/` — хуки, шлют намерения в стор
- `ui/` — компоненты, рисуют готовые результаты
- `data/` — мок, загрузка, localStorage
- `accessible/` — клавиатура: пробел берёт карточку, Tab переключает список и сетку, стрелки двигают фокус, пробел кладёт

## Что не делали специально

Сервер, авторизация, база и вторая страница. В слот можно поставить сверх нормы. Две карточки местами не меняются. `preferredRoomType` — мягкий. `allowedTeacherIds` — ограничение выбора, не шестое правило. В одной клетке может стоять несколько занятий, если преподаватель, аудитория и секция не пересекаются. Выходной из интерфейса не добавляется.

## Отложено из бонусов

Виртуализация списка: `schedule/virtual-window.ts`, заглушка. Когда включат, только у списка, карточка фиксированной высоты, при меньше чем 50 секциях выключена. Screen reader не входит.
